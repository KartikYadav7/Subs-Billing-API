
# Subscription Billing API 

This repository provides a ready-to-run Express + MongoDB backend implementing subscription-based billing with Stripe (test mode) and automated emails using any SMTP provider.Responses are JSON-only (API).

# Features

Product management  
User registration  
Create subscription with chosen products  
Create Stripe Checkout Session for payment   
Webhook handler to confirm payment, update DB, and send confirmation email  
Clean JSON responses
